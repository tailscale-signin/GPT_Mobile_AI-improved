## Storage version, backups and bounded working set

`ChatDatabaseV2` is schema **47**. `ChatDatabaseV2Migrations.MIGRATION_46_47` adds the compact manifest column, checkpoint metadata and durable block/record/manifest/index tables. Published schema 46 is preserved; the new storage is introduced additively.

`CombinedPayload` storage version 2 references immutable content-addressed pages within the owning run. Each logical payload retains page order, lengths and an overall digest. Shared prefixes and unchanged pages can be reused by later checkpoints without overwriting earlier revisions. Version 1 payload descriptors and inline legacy messages remain readable. A page is bounded to 8,192 UTF-16 characters without splitting surrogate pairs; this is not a total-answer limit.

`CombinedSourceReference` carries payload version/block references and deduplicated `framePayloads`/`frameIndexes`. `CombinedDocuments.sourceBlocks` restores the selected source page's code-fence/table framing. It validates source, manifest and run ownership, including archived references. The final/source viewport keeps a bounded cache; an explicit inspector reads a requested original page. Copy/select/export materialization is a deliberate document action rather than a side effect of selecting a contributor tab.

`CombinedDocumentDatabase` and `CompleteBackupDatabase` retain referenced manifests and payloads for conversation-only backups even when full agent history is not selected. The retained set includes historical revisions, nested timeline payloads, original-source pages, frame metadata and minimal owning run rows. Restore checks owner/reference consistency, logical ordering and hashes before replacing destination rows. `CombinedDocuments.portable`/`inlinePortable` materialize full content and strip internal storage references from portable JSON. `CompleteBackupManager` applies the separate history/research selection rules to immutable Research corpora.

`CombinedDocumentStoreTest` includes million-character reopen/export, incremental page reuse, v1 compatibility, stale-fence publication rejection, conversation-only backup integrity, compact archived retry state and bounded original-source reads. These are deterministic regression targets; they do not establish device peak memory or scroll performance.
