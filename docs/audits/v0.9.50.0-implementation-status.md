## Remaining release gates

1. All required CI jobs must pass for the implementation under review, with downloadable evidence. Do not substitute compilation or fixture tests for native execution.
2. Fully download/hash candidate bundles, review redistribution terms and resolved execution metadata, and qualify the permitted normalized outputs. No complete new compiled bundle is admitted yet.
3. Run exact-device GenieX CPU/GPU, qualified Q4_0 NPU, exact-SoC QAIRT and VLM/projector qualification, including G1–G8 cancellation/death/reload/thermal/memory checks. No physical device is attached to this workspace.
4. Complete the statistics lifecycle matrix, delegation T01–T20 and appearance A01–A36, including live permissions, process recreation, backup restore, accessibility focus and translated locales.
5. Record representative same-device before/after statistics/catalog/frame/thermal measurements and paired provider benchmark results. Emulator samples alone cannot establish those budgets or savings.

No merge, tag or release is requested by this draft. The implemented follow-up and observed evidence do not justify describing every design acceptance gate as complete.
