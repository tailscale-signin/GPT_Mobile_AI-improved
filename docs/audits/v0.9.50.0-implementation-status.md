Release remains blocked on successful final-head CI, the full device accessibility/lifecycle matrix, physical Qualcomm/backend qualification, complete bundle validation and representative before/after performance measurements. Resource extraction enables localization but is not proof of translated-locale acceptance. No merge or release is requested by this draft.
