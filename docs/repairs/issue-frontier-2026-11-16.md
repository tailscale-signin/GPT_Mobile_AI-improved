## Required resolution and closure rule

For each issue, obtain an exact commit/ref and app build, a source-owned failure receipt, an observed verification action, and a terminal result. For an unresolved external prerequisite, identify the permission/provider/device owner and retain an open canonical blocker. For a true duplicate, close only after linking the canonical active issue and explaining that duplicate **does not mean fixed**. For a diagnosis-limited report, capture a sanitized source-stage/fingerprint improvement with a reproducible follow-up before disposition. An old report alone is never sufficient to certify current-head behavior.
