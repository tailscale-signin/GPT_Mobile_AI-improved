# 0.9.14.0 release

Version name: `0.9.14.0`. Version code: `69`. Package: `dev.melo.gptmobile.improved`. Minimum Android version: 12 (API 31).

This release includes PR #502 (local MCP marketplace, integrated memory and model delegation) and PR #503 (all 22 audit findings and chronological chat progress). The release artifacts record their immutable source commit and workflow run in `provenance.json`.

The complete user-facing changes, installation details and known limits are in [RELEASE_NOTES.md](../../RELEASE_NOTES.md). Feature ownership and validation are recorded in [audit-implementation.md](../audit-implementation.md).

## Memory defaults

New Fact Vaults start enabled. Existing saved preferences, including disabled memory, are preserved. Capture, recall and cloud recall are independently configurable. Facts remain encrypted locally; selected recalled facts can be sent to configured cloud providers when cloud recall is enabled.

## Release acceptance

- The merged feature implementation passed 1,012 unit tests, debug Android lint, Kotlin formatting, APK compilation, CodeQL and remote diagnostics.
- The signed release workflow reruns unit tests, debug/release lint, Android resource validation and AAR compatibility checks on the exact source commit before building.
- APKs and the AAB must match the package name, version name and version code in the source, and the established release signing certificate.
- The published release includes arm64-v8a, x86_64 and universal APKs, one AAB, SHA-256 checksums and source provenance.
- Physical-device acceptance remains separate from automated validation; see the implementation ledger for pending device scenarios.
