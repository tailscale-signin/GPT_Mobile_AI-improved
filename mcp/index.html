GPT Mobile MCP Tools

Model Context Protocol tools and resources for GPT Mobile AI.

Registered MCP Tools

  • read_file - Read content from local file system with bounded slicing.
  • write_file - Write content safely to local files.
  • list_directory - Enumerate directory contents with metadata.
  • execute_code - Isolated execution for Python and JavaScript snippets.
  • query_database - Read-only query execution for Room/SQLite stores.
  • http_request - Web HTTP query tool supporting GET, POST, PUT, DELETE.
  • translate_text - Offline/online translation across supported locales.

Verification & Integrity

All MCP tool definitions and resources undergo triple verification: manifest schema checking, SHA checksum validation, and read-after-write consistency checks.
