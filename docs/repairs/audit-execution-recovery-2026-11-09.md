# GitHub execution, diagnostics, connector and app-audit repair

## Scope and evidence boundary

This repair is based on `main` at `7db0c735f9e86eaece24513fbaf5c0a624f13822`, on branch `fix/audit-execution-recovery-2026-11-09`. The [task record](audit-execution-recovery-2026-11-09-task.json) identifies the repository, source evidence and intended scope. This document maps all 24 archive findings as **A1–A24**, all 18 additional process-log findings as **L1–L18**, and the original app-audit gaps. Overlapping observations share implementations and tests; they are not counted as independent root causes.

The source reports concern app `0.9.66.7`, build 141, including the selected GitHub conversation and broader process activity. The archive analysis reports eight successful model invocations, 87 tool receipts, no repository mutations in the selected tasks, and no verified final answer. Its principal failure was the gap between durable completed tool receipts and output checkpoints still waiting for those tools. The additional process report covers 4,282 records in `app-diagnostics-9079842559889739562.jsonl`; its older fixture/approval activity is separate from the selected archive tasks. Historical counts below are supplied capture observations, not measurements of this repaired build.

The implementation now observes a tool result after its durable checkpoint commit, reconciles the output handoff, and performs the same reconciliation on restoration. This is a durable-first update with explicit crash-gap recovery, not a claim that two independent stores form one database transaction. Reconciliation uses the call identity and original receipt; an unknown remote outcome or mismatched invocation cannot clear a pending operation. Once all matching receipts are settled, generation can continue without dispatching completed operations again. Production changes are complete for the source-level scope described here. Host regression evidence is recorded below. Full Android compilation, device performance, actual connector deployments, and historical remote cleanup remain separate qualification gates.
