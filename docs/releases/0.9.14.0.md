| Feature | Implementation and acceptance |
| --- | --- |

## Safeguards and boundaries

- Model delegation blocks self-delegation and recursive engine re-entry. It executes subtasks in isolation with strict time and token limits.
- Fact Vault memory is encrypted and opt-in. Recalled facts are not leaked into persistent tool execution traces.
- External MCP connections require valid Streamable HTTP host endpoints.
