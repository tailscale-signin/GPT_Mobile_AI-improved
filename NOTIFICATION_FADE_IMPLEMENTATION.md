## 2. Deep Linking to Conversations

### How It Works

When a user taps a notification, the app opens the specific conversation that generated the notification using the existing deep link mechanism:

```kotlin
val openAppIntent = Intent().setClass(this, MainActivity::class.java).apply {
    flags = Intent.FLAG_ACTIVITY_CLEAR_TOP or Intent.FLAG_ACTIVITY_SINGLE_TOP
    if (chatId != null && chatId > 0) {
        putExtra("chatRoomId", chatId)
    }
}
```

The `lastActiveChatId` is tracked in the service and passed to the pending intent, ensuring users are taken directly to the relevant conversation.

### Notification Flow

1. AI generates a response → Service tracks `lastActiveChatId`
2. Notification is shown with fancy icon
3. User taps notification → App opens with specific chat loaded via `chatRoomId` extra

## 3. Fade-In Effects (0% to 100% over 1 second)

### Files Created/Modified

| File | Changes |
|------|---------|
| `app/src/main/kotlin/dev/chungjungsoo/gptmobile/util/AnimationUtil.kt` | NEW: Utility class for fade-in animations |
| `app/src/main/kotlin/dev/chungjungsoo/gptmobile/presentation/ui/chat/OpponentChatBubble.kt` | MODIFIED: Added fade-in to AI responses |

### Animation Specifications

| Property | Value |
|----------|-------|
| **Duration** | 1000ms (1 second) |
| **Start Opacity** | 0% (fully transparent) |
| **End Opacity** | 100% (fully opaque) |
| **Interpolator** | DecelerateInterpolator |
| **Stagger Delay** | 200ms between multiple bubbles |

### Implementation Details

#### AnimationUtil.kt

```kotlin
object AnimationUtil {
    fun fadeIn(view: View) {
        val animator = ObjectAnimator.ofFloat(view, "alpha", 0f, 1f)
        animator.duration = 1000L // 1 second as requested
        animator.interpolator = DecelerateInterpolator()
        animator.start()
    }
    
    fun fadeInSequentially(views: List<View>, delayMs: Long = 200L) {
        views.forEachIndexed { index, view ->
            val animator = ObjectAnimator.ofFloat(view, "alpha", 0f, 1f)
            animator.duration = 1000L
            animator.interpolator = DecelerateInterpolator()
            animator.startDelay = index.toLong() * delayMs
            animator.start()
        }
    }
}
```

#### OpponentChatBubble.kt (Compose)

```kotlin
// NEW: Fade-in animation for AI response (0% to 100% over 1 second)
AnimatedVisibility(
    visible = shouldShowBubble,
    enter = fadeIn(animationSpec = tween(durationMillis = 1000, easing = DecelerateInterpolator())),
    exit = fadeOut(animationSpec = tween(1000))
) {
    // Bubble content...
}
```

### What Fades In

1. **AI Response Text** - All text generated by the AI model
2. **Tool Call Results** - Output from tool executions
3. **Process Details** - Thinking blocks and tool traces
4. **Chat Bubbles** - Sequential fade for multiple messages

## 6. Performance Considerations

### Optimizations Applied

1. **Native Animations** - Uses `ObjectAnimator` and Compose's native animation system
2. **Hardware Acceleration** - All animations use GPU-accelerated alpha transitions
3. **Throttled Notifications** - Notification updates are throttled to 500ms to save battery
4. **DecelerateInterpolator** - Provides natural feel without excessive CPU usage

### Memory Usage

- AnimationUtil: ~2KB (utility class)
- Notification icons: Vector drawables (no bitmap memory overhead)
- Fade-in animations: Minimal memory footprint
