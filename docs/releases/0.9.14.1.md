# 0.9.14.1 release

Version name: `0.9.14.1`. Version code: `70`. Package: `dev.melo.gptmobile.improved`. Minimum Android version: 12 (API 31).

This patch gives the Free AI platform and tool-result fixes merged in PR #505 an unused release version. The v0.9.14.0 tag already points to an earlier commit and must not be moved to publish newer source.

Release availability is checked before Java/Android setup and Gradle validation. The validated tag and prerelease flag pass to the build job as job outputs. API failures stop the workflow instead of being mistaken for a missing release. Existing release assets remain protected.

Start a new `Publish Signed Release` run on the updated `main` after merging. Re-running the failed workflow uses its original commit and cannot pick up this fix.

The existing test, lint, resource, package/version, signing-certificate and provenance gates still apply. This version change does not itself publish any artifacts.
