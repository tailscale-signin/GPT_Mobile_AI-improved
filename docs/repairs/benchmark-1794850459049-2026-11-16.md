## Observed coverage

- 14 run attempts, 114 cases planned per run = 1,596 case rows.
- 1,582 skipped, 8 errors, 4 unsupported and 2 explicitly canceled; no passed cases.
- Six model admission failures: `SELECTED_MODEL_NOT_LOADED`.
- Four deterministic-policy refusals: `REASONING_OFF_UNSUPPORTED`.
- One attempted tool scenario hit `EXECUTION_FAILED` after three tool rounds and zero successes.
- One gateway HTTP 409 `CLIENT_TOOL_RESULTS_REQUIRED` requires **exact** saved tool receipts; do not blindly restart completed operations.
- Two user-initiated `CHILD_OPERATION_ABORTED` observations are cancellations, not provider outages.

## Applied source changes

1. Expose **Saved profile settings** (default) versus opt-in **Strict deterministic** policy. Never switch the selected model without explicit selection, and keep scoring cohorts policy-separated.
2. Grade a model that exhausts all three completed tool rounds as `MODEL_TOOL_ROUND_LIMIT`, retaining the attempted calls and allowing independent cases to continue. Provider faults and unresolved 409s remain profile blockers.
3. Label invalid model tool arguments `MODEL_TOOL_ARGUMENTS_INVALID` without treating them as infrastructure failures.
4. Add host regression tests for both reasoning policy choices, exhausted invalid fixture rounds and pending result stop behavior.

## Still unverified and not claimed fixed

- Gateway 409 reconciliation requires a persisted exact pending-tool batch, call IDs and result receipts from the Windows service. Automatic replay or fabrication would be unsafe.
- A selected model must be demonstrably loaded and ready on the live gateway. This cannot be certified with Android host unit tests.
- Tool fixtures are offline synthetic operations. They do not establish real GitHub authorization, upstream read consistency, write/merge correctness or branch-protection permissions.
- Voice playback, microphone use and remote DNS/circuit-breaker reports require physical-device or live transport reproduction.
- Cases skipped due to profile admission do not count as tool-capability failures.
